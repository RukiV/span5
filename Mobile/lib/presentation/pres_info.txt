=================================================================================
"fbs_toep/lib/presentation/..."
    This layer is responsible for everything the user sees and interacts with.
    It represents the visual face of the Facility Management System.
=================================================================================

"views/..."
    Contains the full-page UI components.

"widgets/..."
    Reusable UI building blocks like custom buttons, cards, or the camera UI.

"state/..."
    Manages the UI's memory and logic, such as tracking which user is logged
    in and their assigned role.
