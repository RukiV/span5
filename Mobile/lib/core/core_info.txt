=================================================================================
"fbs_toep/lib/core/..."
    This directory houses the application's infrastructure and shared components
    that are independent of any specific feature. It ensures a unified look and
    feel and consistent behavior across the entire application:
=================================================================================

"constants/..."
    Contains static values like:
    --> Staff domain (@akademia.ac.za)
    --> Student domain (@akademiastudente.co.za)

"network/..."
    Home to the DioClient. This is the central point for managing API requests
    to the FastAPI backend.

"theme/..."
    Defines the visual identity, such as colors and typography.

"utils/..."
    Contains small helper functions like email validators or date formatters.
