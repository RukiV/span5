=================================================================================
"fbs_toep/lib/data/..."
    The data layer is responsible for all information handling. It manages how
    data is fetched from the backend, how it's stored, and how it's converted
    into Dart objects.
=================================================================================

"models/..."
    Contains blueprints for entities, converting JSON into Dart objects.

"services/..."
    The logic that performs the actual network requests. This includes the
    "AuthService" for Outlook and manual logins.

"repositories/..."
    Acts as a mediator between the data sources (services) and the UI, deciding
    where to fetch data from.
